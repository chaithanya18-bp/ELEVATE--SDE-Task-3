# ELEVATE--SDE-Task-3
CredVault – Task 3

Project Description

CredVault is a secure credential management application developed as part of the Elevate Skills SDE Internship Task 3.

Features

- Backend development using Node.js
- Express.js server
- SQLite database
- JWT authentication
- CORS support
- Secure API development

Technologies Used

- HTML, CSS, JavaScript
- Node.js
- Express.js
- SQLite
- JSON Web Token (JWT)

Installation

1. Clone or download the repository.
2. Install dependencies:

npm install

3. Start the server:

node server.js
